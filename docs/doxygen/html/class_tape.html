Opis szczegółowy

Modeluje nieskończoną taśmę przechowywaną jako rzadka mapa komórek.

Taśma zapisuje tylko komórki różne od symbolu pustego. Dzięki temu puste obszary po lewej i prawej stronie wejścia nie zajmują pamięci, a odczyt nieustawionej pozycji zawsze zwraca blankSymbol_.
