Opis szczegółowy

Główne okno symulatora z kartami dokumentów i paskiem menu.

Odpowiada za tworzenie kart MachineEditorTab, stronę startową, akcje menu, przełączanie motywu oraz operacje wysokiego poziomu delegowane do bieżącej karty maszyny.
