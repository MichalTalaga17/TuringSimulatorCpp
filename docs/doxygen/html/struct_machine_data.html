Opis szczegółowy

Dane definicji maszyny odczytane z trwałego nośnika.

Struktura jest niezależna od UI. Warstwa MachineEditorTab używa jej do odtworzenia pól formularza, tabeli przejść i parametrów rdzenia maszyny.
