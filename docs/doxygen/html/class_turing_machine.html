Opis szczegółowy

Udostępnia logikę jednotaśmowej deterministycznej maszyny Turinga.

Klasa przechowuje stan sterowania, taśmę, zbiór stanów akceptujących oraz deterministyczną funkcję przejścia. Warstwa UI buduje tę klasę z formularza, a potem wykonuje symulację przez kolejne wywołania step().
