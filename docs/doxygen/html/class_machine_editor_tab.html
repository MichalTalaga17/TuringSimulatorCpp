Opis szczegółowy

Pojedyncza karta edycji i uruchamiania maszyny Turinga.

Klasa łączy formularz definicji maszyny, tabelę przejść, widok taśmy, sterowanie symulacją oraz operacje zapisu/odczytu. Logika została rozdzielona na kilka plików .cpp, ale wszystkie metody należą do tej jednej klasy widżetu.
